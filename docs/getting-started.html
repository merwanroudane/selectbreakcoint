Getting Started

Install selectbreakcoint and learn the basics of structural break detection in cointegrating regressions.

Installation

Install selectbreakcoint using pip:

pip install selectbreakcoint

Or install from source:

git clone https://github.com/merwanroudane/selectbreakcoint.git
cd selectbreakcoint
pip install -e .

Dependencies

The package requires the following dependencies (automatically installed):

  • NumPy >= 1.20.0
  • SciPy >= 1.7.0
  • scikit-learn >= 1.0.0
  • pandas >= 1.3.0
  • statsmodels >= 0.13.0

Quick Start

1. Detecting Structural Breaks

The main class for break detection is AdaptiveLassoBreaks:

import numpy as np
from selectbreakcoint import AdaptiveLassoBreaks

# Generate cointegrated data with a structural break at t=100
np.random.seed(42)
T = 200
x = np.cumsum(np.random.randn(T))  # I(1) regressor

# Create y with break at t=100:
# Before: y = 2 + 2*x + error
# After:  y = 4 + 4*x + error
e = np.random.randn(T) * 0.5
y = np.where(
    np.arange(T) < 100,
    2 + 2 * x + e,
    4 + 4 * x + e
)

# Estimate structural breaks
model = AdaptiveLassoBreaks(max_breaks=2, trim=0.05)
result = model.fit(x, y)

# View results
print(result)

💡 Tip

The max_breaks parameter specifies the maximum number of breaks to search for. The algorithm will detect the optimal number up to this limit.

2. Understanding the Results

The BreakEstimationResult object contains:

# Number of detected breaks
print(f"Breaks detected: {result.n_breaks}")

# Break locations (as fractions and indices)
print(f"Break fractions: {result.break_fractions}")
print(f"Break dates: {result.break_dates}")

# Regime-specific coefficients
print(f"Intercepts by regime: {result.regime_intercepts}")
print(f"Slopes by regime: {result.regime_slopes}")

# Model fit statistics
print(f"BIC: {result.bic}")
print(f"MSE: {result.mse}")

3. Cointegration Testing

Test for cointegration while allowing for structural breaks:

from selectbreakcoint import CointegrationTest

# Create test with up to 2 breaks
test = CointegrationTest(
    max_breaks=2,
    test_type='adf',      # or 'zt' for bias-corrected
    lag_selection='aic'   # or 'bic', 'fixed'
)

# Run the test
result = test.test(x, y)

# View results
print(result)

# Check if cointegrated at 5% level
print(f"Cointegrated? {result.is_cointegrated}")

# Get critical values
print(f"Critical values: {result.critical_values}")

⚠️ Important

The null hypothesis is no cointegration. Rejecting the null (test statistic below critical value) indicates evidence of cointegration.

Using Real Data

Example: Lütkepohl Consumption-Investment Data

Here's how to use selectbreakcoint with real economic data:

import pandas as pd
import numpy as np
from selectbreakcoint import AdaptiveLassoBreaks, CointegrationTest

# Load your data (example: consumption and investment)
# Data should be in log levels for cointegration analysis
data = pd.read_excel('lutkepohl2.xlsx')
print(data.head())

# Extract variables
cons = data['CONS'].values  # Log consumption
inv = data['INV'].values    # Log investment

# Step 1: Test for unit roots (both should be I(1))
from selectbreakcoint import adf_test

adf_cons, lag_cons, _ = adf_test(np.diff(cons))
adf_inv, lag_inv, _ = adf_test(np.diff(inv))
print(f"ADF on Δcons: {adf_cons:.3f}")  # Should reject (stationary)
print(f"ADF on Δinv: {adf_inv:.3f}")    # Should reject (stationary)

# Step 2: Detect structural breaks in the cointegrating relationship
model = AdaptiveLassoBreaks(
    max_breaks=2,
    trim=0.05,
    dynamic_lags=2  # For endogeneity correction
)

result = model.fit(inv, cons)  # cons = α + β*inv + u

print("\n=== Break Detection Results ===")
print(result)

# Step 3: Test for cointegration with structural breaks
test = CointegrationTest(max_breaks=2, test_type='adf')
test_result = test.test(inv, cons)

print("\n=== Cointegration Test Results ===")
print(test_result)

Interpreting Results

The output provides:

  • Break dates: When the relationship changed (as time indices and fractions)
  • Regime coefficients: The intercept (μ) and slope (β) for each regime
  • Parameter changes: How much each coefficient changed at each break
  • Test statistics: For determining if cointegration exists

Working with Known Break Candidates

If you have prior information about when breaks might occur (e.g., policy changes, crises), you can specify them:

# Specify known break candidates as fractions of sample
# For a sample of T=200, breaks at t=50, 100, 150 would be:
known_breaks = [0.25, 0.5, 0.75]

model = AdaptiveLassoBreaks(max_breaks=3)
result = model.fit(x, y, known_breaks=known_breaks)

# The algorithm will select which of these are actually active
print(f"Active breaks: {result.break_fractions}")
print(f"Inactive candidates were eliminated")

💡 When to use known breaks

Use known break candidates when you have economic reasons to believe breaks occurred at specific times (e.g., financial crises, policy changes, regime shifts). This can improve estimation accuracy.

Handling Endogeneity

When the regressor may be endogenous, use dynamic augmentation following Saikkonen (1991) and Stock & Watson (1993):

# Add leads and lags of the differenced regressor
model = AdaptiveLassoBreaks(
    max_breaks=4,
    dynamic_lags=2  # Include 2 leads and 2 lags of Δx
)

result = model.fit(x, y)

# This corrects for potential endogeneity bias
# in the coefficient estimates

The dynamic augmentation adds terms Δx_{t-k}, ..., Δx_{t}, ..., Δx_{t+k} to the regression, which asymptotically removes the bias caused by correlation between the regressor and the error term.
