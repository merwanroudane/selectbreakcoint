API Reference

Complete documentation of all classes, methods, and utility functions.

Main Classes

AdaptiveLassoBreaks Class

Main class for detecting and estimating multiple structural breaks in cointegrating regressions using the adaptive lasso approach.

from selectbreakcoint import AdaptiveLassoBreaks

model = AdaptiveLassoBreaks(
    max_breaks=1,           # Maximum number of structural breaks
    trim=0.05,              # Lateral trimming parameter (5%)
    min_obs=1,              # Minimum observations per regime
    n_lambda=100,           # Number of lambda values in grid
    gamma=1.0,              # Exponent for adaptive lasso weights
    penalty_type='bic_star',# Model selection criterion
    dynamic_lags=0          # Leads/lags for endogeneity correction
)

Parameters

max_breaks int, default=1

Maximum number of structural breaks to detect. The algorithm will find the optimal number up to this limit.

trim float, default=0.05

Lateral trimming parameter. Excludes the first and last trim×100% of observations as potential break points.

min_obs int, default=1

Minimum number of observations per regime.

n_lambda int, default=100

Number of lambda values in the regularization path grid.

gamma float, default=1.0

Exponent for adaptive lasso weights. Higher values increase penalization of small coefficients.

penalty_type str, default='bic_star'

Model selection criterion. Options: 'bic' (standard BIC), 'bic_star' (modified BIC for diverging parameters).

dynamic_lags int, default=0

Number of leads and lags of the differenced regressor to include for endogeneity correction.

Methods

fit(x, y, known_breaks=None)

Estimate structural breaks. Returns BreakEstimationResult.

predict(x_new)

Predict y values using the fitted model. Returns predicted values array.

get_residuals()

Get model residuals. Returns residuals array.

CointegrationTest Class

Class for testing cointegration while allowing for multiple structural breaks. Implements Algorithm 2 from Schmidt and Schweikert (2021).

from selectbreakcoint import CointegrationTest

test = CointegrationTest(
    max_breaks=1,           # Maximum number of structural breaks
    trim=0.05,              # Lateral trimming parameter
    test_type='adf',        # Test type: 'adf' or 'zt'
    lag_selection='aic',    # Lag selection method
    n_lambda=100,           # Number of lambda values
    dynamic_lags=0          # Leads/lags for endogeneity
)

Parameters

max_breaks int, default=1

Maximum number of structural breaks to allow under the alternative hypothesis.

trim float, default=0.05

Lateral trimming parameter.

test_type str, default='adf'

Test statistic type. 'adf' for ADF-type, 'zt' for bias-corrected Z_t statistic.

lag_selection str, default='aic'

Lag order selection method for ADF test. Options: 'aic', 'bic', 'fixed'.

n_lambda int, default=100

Number of lambda values in the grid.

dynamic_lags int, default=0

Number of leads and lags for dynamic augmentation.

Methods

test(x, y)

Perform cointegration test. Returns CointegrationTestResult.

is_cointegrated(significance=0.05)

Check if series are cointegrated at given significance level. Returns boolean.

get_breaks()

Get estimated break dates and fractions. Returns tuple (break_fractions, break_dates).

Result Classes

BreakEstimationResult Dataclass

Container for structural break estimation results. Returned by AdaptiveLassoBreaks.fit().

Attributes

n_breaks int

Number of detected structural breaks.

break_fractions np.ndarray

Estimated break fractions τ ∈ (0, 1).

break_dates np.ndarray

Estimated break date indices.

intercept_coefs np.ndarray

Baseline intercept coefficients (μ*₁).

slope_coefs np.ndarray

Baseline slope coefficients (β*₁).

intercept_changes np.ndarray

Parameter changes at each break (μ*ᵢ for i > 1).

slope_changes np.ndarray

Parameter changes at each break (β*ⱼ for j > 1).

residuals np.ndarray

Estimated residuals from the cointegrating regression.

bic float

BIC value for the selected model.

optimal_lambda float

Optimal tuning parameter from adaptive lasso.

sample_size int

Sample size T.

Properties

regime_intercepts np.ndarray

Intercept values for each regime (cumulative sum of baseline + changes).

regime_slopes np.ndarray

Slope values for each regime (cumulative sum of baseline + changes).

ssr float

Sum of squared residuals.

mse float

Mean squared error.

Methods

summary()

Generate a formatted summary string of results.

to_dict()

Convert result to dictionary for serialization.

CointegrationTestResult Dataclass

Container for cointegration test results. Returned by CointegrationTest.test().

Attributes

test_statistic float

Test statistic value (ADF or Z_t).

critical_values dict

Critical values at different significance levels {0.01: cv, 0.05: cv, 0.10: cv}.

reject_null dict

Boolean indicators for rejection at each significance level.

test_type str

Type of test ('adf' or 'zt').

n_breaks int

Number of breaks in the selected model.

break_fractions np.ndarray

Estimated break fractions under the alternative.

break_dates np.ndarray

Estimated break dates under the alternative.

Properties

is_cointegrated bool

True if null hypothesis of no cointegration is rejected at 5% level.

Test Functions

adf_test Function

Augmented Dickey-Fuller test on residuals.

from selectbreakcoint import adf_test

adf_stat, selected_lag, coefs = adf_test(
    residuals,              # Residuals from cointegrating regression
    max_lags=None,          # Maximum lags (default: T^(1/3))
    lag_selection='aic'     # 'aic', 'bic', or 'fixed'
)

Returns

adf_stat float

ADF test statistic (t-ratio for ρ).

selected_lag int

Selected lag order.

coefs np.ndarray

Coefficients from the ADF regression.

phillips_perron_test Function

Phillips-Perron test for unit root in residuals with bias-corrected Z_t statistic.

from selectbreakcoint import phillips_perron_test

z_t, rho_hat, sigma2 = phillips_perron_test(
    residuals,              # Residuals from cointegrating regression
    bandwidth=None          # Bandwidth for long-run variance (default: Newey-West)
)
engle_granger_test Function

Engle-Granger two-step cointegration test (no structural breaks).

from selectbreakcoint import engle_granger_test

result = engle_granger_test(y, x, max_lags=None, test_type='adf')
print(f"Cointegrated? {result.is_cointegrated}")
gregory_hansen_test Function

Gregory-Hansen cointegration test with one structural break.

from selectbreakcoint import gregory_hansen_test

result = gregory_hansen_test(
    y, x,
    model='C/S',    # 'C' (level), 'C/T' (level+trend), 'C/S' (regime shift)
    trim=0.15       # Trimming parameter
)
print(f"Break date: {result.break_dates[0]}")
hatemi_j_test Function

Hatemi-J cointegration test with two structural breaks.

from selectbreakcoint import hatemi_j_test

result = hatemi_j_test(y, x, trim=0.15)
print(f"Break dates: {result.break_dates}")

Utility Functions

get_critical_values Function

Retrieve critical values from Schmidt and Schweikert (2021) tables.

from selectbreakcoint import get_critical_values

cv = get_critical_values(
    max_breaks=2,           # Maximum breaks (1-6)
    sample_size=200,        # T=100, 200, 400, or 'asymptotic'
    test_type='adf'         # 'adf' or 'zt'
)
print(cv)  # {0.01: -5.23, 0.05: -4.71, 0.10: -4.42}
construct_break_indicators Function

Construct indicator variables for structural breaks.

from selectbreakcoint import construct_break_indicators

# Create indicators for breaks at 30% and 70% of sample
indicators = construct_break_indicators(
    T=100,                      # Sample size
    break_fractions=[0.3, 0.7], # Break fractions
    include_baseline=True       # Include column of ones
)
# Shape: (100, 3) - baseline + 2 break indicators
compute_bic Function

Compute the Bayesian Information Criterion.

from selectbreakcoint import compute_bic

bic = compute_bic(residuals, n_params=4, T=200)
# BIC = log(SSR/T) + log(T)/T * df
compute_modified_bic Function

Compute the modified BIC for diverging number of parameters (Wang, Li & Leng, 2009).

from selectbreakcoint import compute_modified_bic

bic_star = compute_modified_bic(
    residuals, 
    n_params=4,         # Non-zero parameters
    T=200,              # Sample size
    n_total_params=50   # Total potential parameters
)
dynamic_augmentation Function

Construct leads and lags of first-differenced regressor for endogeneity correction.

from selectbreakcoint import dynamic_augmentation

z_data = dynamic_augmentation(x, k=2)
# Returns matrix of shape (T, 2*k+1) with Δx and its leads/lags
hausdorff_distance Function

Compute Hausdorff distance between estimated and true break points.

from selectbreakcoint import hausdorff_distance

# Measure accuracy of break date estimation
hd = hausdorff_distance(
    estimated_breaks=[0.32, 0.68],  # Estimated fractions
    true_breaks=[0.33, 0.67]        # True fractions
)
print(f"Hausdorff distance: {hd:.4f}")  # 0.01
