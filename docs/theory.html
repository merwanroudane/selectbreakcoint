Theory

Mathematical foundations and econometric methodology behind structural break detection in cointegrating regressions.

Cointegration Fundamentals

Definition: Cointegration

Two I(1) series yt and xt are cointegrated if there exists a linear combination yt - βxt that is stationary (I(0)). The parameter β is the cointegrating coefficient.

The standard cointegrating regression is:

yt = μ + βxt + ut,    t = 1, ..., T

where:

  • yt is the dependent variable (I(1))
  • xt is the regressor (I(1))
  • μ is the intercept
  • β is the cointegrating coefficient
  • ut is the equilibrium error (I(0) under cointegration)

Testing for Cointegration

The Engle-Granger two-step procedure tests H₀: No cointegration by:

  1. Estimating the cointegrating regression by OLS
  2. Testing the residuals ût for a unit root using an ADF test

The test statistic is the t-ratio from the ADF regression:

Δût = ρût-1 + Σj=1k γjΔût-j + εt

Cointegration with Structural Breaks

The key insight of Schmidt and Schweikert (2021) is that standard cointegration tests may fail to detect cointegration when structural breaks are present. The extended model allows for m structural breaks:

yt = Σi=1m₁+1 μ*iφt,τ₁,ᵢ₋₁ + Σj=1m₂+1 β*jxtφt,τ₂,ⱼ₋₁ + ut

where:

  • φt,τ = 1(t > ⌊Tτ⌋) is the indicator function
  • τ₁,ᵢ are break fractions for the intercept
  • τ₂,ⱼ are break fractions for the slope
  • m₁, m₂ are the number of breaks in intercept and slope

Equivalent Formulation

The model can be rewritten with baseline coefficients and parameter changes:

yt = μ₁ + Σi=2m₁+1 δμiφt,τ₁,ᵢ₋₁ + β₁xt + Σj=2m₂+1 δβjxtφt,τ₂,ⱼ₋₁ + ut

where δμi and δβj represent the changes in coefficients at each break.

Adaptive Lasso Methodology

The Challenge

When the number and location of breaks are unknown, the problem becomes one of model selection in a high-dimensional setting. Schmidt and Schweikert (2021) propose using the adaptive lasso to simultaneously select breaks and estimate coefficients.

Adaptive Lasso Estimator

The adaptive lasso minimizes the penalized objective function:

VT(β) = Σt=1T(yt - Xt'β)² + λT Σj=1p wj|βj|

where the adaptive weights are:

wj = 1 / |β̃j|γ

and β̃j are initial consistent estimates (from plain lasso).

Theorem 1: Oracle Property

Under regularity conditions, the adaptive lasso estimator possesses the oracle property:

  1. Sparsity: β̂j = 0 for all inactive (zero) coefficients with probability tending to 1
  2. Efficiency: The estimator of active coefficients achieves the same asymptotic distribution as if the true model were known

Algorithm 1: Three-Step Procedure

Following Section 2.2 of Schmidt and Schweikert (2021):

1

Initial Lasso

Apply plain lasso (wj = 1) to the full model with all potential break points. Select λT using BIC*.

2

Adaptive Lasso

Compute adaptive weights from Step 1 estimates. Apply adaptive lasso with weights wj = 1/|β̃j|γ.

3

Post-Lasso OLS

Estimate the final model by OLS using only the selected breaks. Add intercept breaks at slope break locations.

Model Selection

Standard BIC

The Bayesian Information Criterion for model selection:

BIC(λ) = log(SSR/T) + (log T / T) × df

where df is the number of non-zero coefficients.

Modified BIC (BIC*)

For the diverging parameter setting, Wang, Li & Leng (2009) propose the modified BIC:

BIC*(λ) = log(SSR/T) + (log T / T) × df × log(log(d*T))

where d*T is the total number of potential parameters. This modification provides consistent model selection when the number of parameters grows with the sample size.

Cointegration Testing with Breaks

Algorithm 2: Infimum Test

Following Section 2.3 of Schmidt and Schweikert (2021), the cointegration test proceeds as:

  1. For each tuning parameter λ, estimate breaks using adaptive lasso
  2. Re-estimate using post-lasso OLS
  3. Test residuals using ADF or bias-corrected Zt statistics
  4. Select the model specification that minimizes the test statistic (infimum test)
t* = infλ∈Λ tADF(λ)

Test Statistics

ADF-Type Statistic

The t-ratio from the ADF regression on residuals:

tADF = ρ̂ / se(ρ̂)

Bias-Corrected Zt Statistic

Following Phillips (1987), the bias-corrected estimator accounts for serial correlation:

Zt = (ρ* - 1) / √(σ̂² / Σû²t-1)

where ρ* is the bias-corrected autoregressive coefficient and σ̂² is the long-run variance estimate.

Critical Values

Critical values from Table 1 of Schmidt and Schweikert (2021) depend on:

  • Maximum number of breaks allowed (1-6)
  • Sample size (T = 100, 200, 400, or asymptotic)
  • Test type (ADF or Zt)

The package includes all tabulated critical values for accurate inference.

Endogeneity Correction

When regressors are potentially endogenous, Saikkonen (1991) and Stock and Watson (1993) propose augmenting the regression with leads and lags of the differenced regressor:

yt = μ + βxt + Σj=-kk γjΔxt-j + u*t

This dynamic augmentation:

  • Asymptotically removes endogeneity bias
  • Yields efficient estimates of the cointegrating coefficient
  • Allows for weak exogeneity violation

In the package, set dynamic_lags=k to include k leads and lags.

Alternative Methods

Gregory-Hansen Test (1996)

Tests for cointegration allowing for a single structural break at an unknown date. The test minimizes the ADF statistic over all possible break points:

t*GH = infτ∈[τ₀, 1-τ₀] tADF(τ)

Models available: C (level shift), C/T (level shift with trend), C/S (regime shift).

Hatemi-J Test (2008)

Extends Gregory-Hansen to allow for two structural breaks. The test searches over all possible pairs of break points:

t*HJ = infτ₁, τ₂ tADF(τ₁, τ₂)

Subject to minimum regime size constraints.
