Structural Breaks in Cointegrating Regressions

A Python implementation of the adaptive lasso methodology for detecting and estimating multiple structural breaks in cointegrating regressions.

Based on Schmidt & Schweikert (2021) — Studies in Nonlinear Dynamics & Econometrics

Get Started View Examples
$ pip install selectbreakcoint
Features

Comprehensive Toolkit for
Cointegration Analysis

Structural Break Detection

Detect multiple structural breaks in both intercept and slope coefficients of cointegrating regressions using adaptive lasso.

Oracle-Efficient Estimation

Adaptive lasso estimator with proper treatment of non-stationary regressors, proven to have oracle properties.

Cointegration Testing

Residual-based tests for cointegration allowing for multiple structural breaks with proper critical values.

Flexible Model Specification

Support for known breakpoint candidates and diverging number of unknown break dates.

Complete Critical Values

Tables from Schmidt & Schweikert (2021) for ADF and Z_t statistics with 1-6 breaks.

Comparison Methods

Gregory-Hansen, Hatemi-J, and Engle-Granger tests included for benchmarking.

Quick Example

Detect Breaks in Minutes

import numpy as np
from selectbreakcoint import AdaptiveLassoBreaks

# Generate cointegrated data with a structural break
np.random.seed(42)
T = 200
x = np.cumsum(np.random.randn(T))  # I(1) regressor

# y with break at t=100 (intercept: 2→4, slope: 2→4)
e = np.random.randn(T) * 0.5
y = np.where(np.arange(T) < 100,
             2 + 2 * x + e,
             4 + 4 * x + e)

# Estimate structural breaks
model = AdaptiveLassoBreaks(max_breaks=2, trim=0.05)
result = model.fit(x, y)

print(result)
# Output shows detected break at t≈100
from selectbreakcoint import CointegrationTest

# Test for cointegration with structural breaks
test = CointegrationTest(
    max_breaks=2, 
    test_type='adf',
    lag_selection='aic'
)

result = test.test(x, y)

print(result)
print(f"Cointegrated at 5%? {result.is_cointegrated}")
# Outputs test statistic, critical values, and conclusion
# If you have prior information about break dates
model = AdaptiveLassoBreaks(max_breaks=3)

# Pass known break candidates as fractions of sample
result = model.fit(x, y, known_breaks=[0.25, 0.5, 0.75])

print(f"Detected breaks at: {result.break_fractions}")
print(f"Regime intercepts: {result.regime_intercepts}")
print(f"Regime slopes: {result.regime_slopes}")
Methodology

Three-Step Adaptive Lasso Procedure

Following Algorithm 1 from Schmidt & Schweikert (2021)

1

Initial Lasso

Apply plain lasso to the full model with all potential break points. Uses lateral trimming (5%) to exclude breaks at boundaries.

λ_T selected via BIC*
2

Adaptive Lasso

Use adaptive weights w_j = 1/|β̂_j|^γ to distinguish active from inactive breaks with oracle property.

V_T = Σ(y_t - X_t'β)² + λ_T Σ w_j^γ |β_j|
3

Post-Lasso OLS

Final estimation with selected breaks. Adds intercept breaks at same timing as slope breaks.

Consistent estimation of μ*, β*
